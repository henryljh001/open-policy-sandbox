# 路线图｜Policy Sandbox

## 阶段 0：独立工程与公开边界（部分完成）

独立工程目录、Apache-2.0、治理文件、核心 schema、隔离扫描和版本快照已完成。Git 仓库尚无首个跟踪基线、标签和远端；`_versions` 文件快照不等同于 Git 历史。完成源码绑定复验前，阶段 0 不得标为全部完成。

## 阶段 1：合成政策沙盒纵切（已完成）

- I0 领域规划与注册；
- I1 合成状态与守恒基线；
- I2 七类政策工具与 S0—S8 情景；
- I3 合成家庭、随机行为、五类压力、分组与重复实验；
- I4 公平比较、群体差距、财政土地账、Pareto 前沿、一页纸与审计包。

## 阶段 2：经验校准与新型城镇化 MVP（进行中）

### I5a 适配器协议与合成校准闭环（已完成）

- 注册式汇总数据适配器、严格工厂和自动发现；
- 数据卡、八指标词典、单位/年份/重复/授权硬校验；
- 合成 fixture、校准运行、来源摘要和 Schema；
- 审计结果始终保留 `U6_status=not_passed`。

### I5b 授权汇总数据适配（待授权）

1. 冻结公开汇总指标词典、空间/时间口径、许可和来源定位；
2. 在私有运行环境实现来源读取器，公开仓库只保留协议和合成 fixture；
3. 形成缺失、修订、单位换算和跨期可比性报告；
4. 真实目标包保留在私有环境；仅生成经授权、最小化且通过披露风险评估的输出，不复制受限原始数据。

### I6 真实校准、回溯与专家门（待完成）

交付校准前后差异、容差、灵敏度、留出验证、外推边界和专家审阅。聚合层与家庭/群体分配层按能力分别裁决；未通过 U6 前保持 Demo，未通过 U8 前不得标 Decision-support。

## 阶段 3：决策工作台

界面消费稳定契约，提供政策解读、情景向导、多方案比较、外推提示、方法附录、权限和审计日志；不得在前端重算结果或隐藏警告。首个候选仅允许单用户、本地运行且不接收真实数据上传。

## 阶段 4：开放生态

语义化版本、软件物料清单和稳定软件发布可先行；插件/适配器 SDK、第三方模板和自动发布延后到至少两个独立适配器或插件证明契约稳定后。
