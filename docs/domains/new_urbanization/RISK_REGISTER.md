# 风险登记｜新型城镇化插件

| 风险 | 严重度 | 早期信号 | 控制 |
|---|---:|---|---|
| 把城镇化率当唯一目标 | 致命 | 只比较率，不比较就业/服务/成本 | 多目标与群体差距强制输出 |
| 政策目标被当因果参数 | 致命 | 参数直接等于规划目标 | 事实与假设分层，效应显式标 synthetic |
| 合成家庭被误认作真实个人 | 致命 | 报告出现个体预测或画像 | 无 PII、合成 ID、禁止导出个体决策 |
| 聚合与微观双重记账 | 致命 | 两层分别改变总人口 | 聚合层权威；家庭只调权重和构成 |
| 县域/城区/城镇口径混用 | 致命 | 人口分母、边界不一致 | schema 强制 scale/boundary/caliber |
| 行为概率被误作经验参数 | 高 | 参数无来源却标“预测” | 配置可见、Demo 标签、U6 前禁止外推 |
| 盲目扩张被模型奖励 | 高 | 建设投入总能提高效用 | 财政、土地、闲置和运营成本硬约束 |
| 人口收缩地区套增长模型 | 高 | 所有地区使用同一响应 | 五类县域分型，收缩情景独立 |
| 公共服务容量虚构 | 高 | 资格覆盖即视为实际享有 | 资格、使用、容量和拥挤分开 |
| 微观使用突破聚合容量 | 致命 | 就业/住房/服务使用量大于容量 | 每年硬断言，失败而非只警告 |
| 财政账不闭合 | 高 | 只计建设、不计运营债务 | 全周期余额、债务与失败门 |
| 压力失败率被当真实风险概率 | 致命 | 报告称“灾害发生概率” | 明示配置机制，只作模型稳健性 |
| 空间外推 | 高 | 省级参数直接套县域 | scale 标签、分布外警告、区域校准 |
| LLM agent 不稳定 | 高 | 相同输入行为大幅漂移 | 默认关闭、规则基线、重复和结构化输出 |
| 总量改善掩盖弱势群体损失 | 高 | 仅报告平均值 | 技能、来源、家庭和空间分组默认输出 |
| 真实数据许可不清 | 高 | 数据无来源或无法公开 | 数据卡、授权、私有目录隔离 |
| 复杂度失控 | 中 | 同时开发多领域多引擎 | 严守 MVP 和阶段退出门 |
| 管理者把情景当预测 | 高 | 使用“将会”“准确预测” | 使用等级、区间、假设和责任说明 |

## 停止条件

出现政策事实无法回指、人口/财政/土地不守恒、微观使用突破容量、未授权数据进入仓库、模型等级被夸大、合成家庭被用于个人判断或真实地区结果被误称预测时，立即停止发布并回退到最近通过闸门的版本。
