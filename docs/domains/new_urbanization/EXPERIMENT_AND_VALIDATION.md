# 情景实验与验证方案

## 1. 基础情景矩阵

| 编号 | 情景 | 主要政策工具 | 目的 |
|---|---|---|---|
| S0 | 趋势基线 | 不叠加政策工具 | 建立对照 |
| S1 | 落户放宽 | 降低落户门槛、居住登记 | 检验制度门槛效应 |
| S2 | 服务随人 | 教育、医疗等资格与常住人口挂钩 | 检验公共服务约束 |
| S3 | 就业优先 | 技能培训、岗位和就业服务 | 检验岗位吸纳与技能匹配 |
| S4 | 县城扩容 | 设施、住房和有限空间扩张 | 检验承载能力与财政成本 |
| S5 | 存量提质 | 盘活存量、提高设施效率 | 对照增量扩张 |
| S6 | 综合市民化 | S1+S2+S3，按容量约束实施 | 检验政策协同 |
| S7 | 高投入扩张 | 大规模建设、无就业联动 | 识别盲目扩张风险 |
| S8 | 收缩适配 | 控增量、集中服务、转移支持、盘活存量 | 适配人口流失地区 |

九个情景可在同一县域类型、起始年和随机种子下运行聚合或家庭微观引擎。

## 2. 五类压力

| 压力 | 聚合通道 | 家庭通道 | 预期诊断 |
|---|---|---|---|
| 就业下行 | 岗位、就业、财政收入 | 匹配下降、迁出上升 | 就业和稳定市民化下降 |
| 财政收紧 | 转移、收入、设施增长 | 安居和服务落实下降 | 服务、住房或债务风险 |
| 迁入超预期 | 净迁移上升 | 迁入上升、容量竞争 | 人口上升并挤压住房服务 |
| 人口老龄化 | 劳动年龄占比和医疗 | 户内老龄转换 | 老年占比和医疗压力上升 |
| 极端事件 | 就业、财政、设施 | 分配下降、显式失效概率 | 区间变宽并出现失败运行 |

压力只接受显式合成配置。任何压力效应都不是对真实宏观、人口或灾害概率的估计。

## 3. 随机实验设计

- 默认合成家庭：1 万户；测试可下调，生产演示可上调至 10 万户；
- 年度顺序：聚合更新 → 权重对齐 → 迁移/老龄化 → 就业 → 落户 → 住房 → 服务；
- 默认重复：100 次，种子为 `base_seed + offset`；
- 总体汇总：均值、标准差、P05、P50、P95；
- 失败汇总：成功数、失败数、失败率和原因计数；
- 分组：技能、来源、家庭结构和空间位置；
- 固定种子与配置必须得到字节级相同结果。

## 4. 校准层级

1. **结构校准**：人口、岗位、住房、服务、财政和土地状态一致；
2. **总体矩校准**：复现基期人口、就业、服务和财政分布；
3. **行为校准**：迁移、就业和住房参数来自可核实证据；
4. **动态校准**：历史期内变化趋势不系统偏离；
5. **区域校准**：不同县城类型使用不同参数。

I3 完成第 1 层和第 2 层的软件接口。当前测试目标均为合成目标，不构成 U6 经验校准。

## 5. 当前方向与约束测试

- 综合市民化相对 S0 提高稳定市民化率；
- 就业下行降低家庭就业率；
- 财政收紧降低转移收入并压低服务/安居概率；
- 迁入超预期提高聚合人口并增加容量竞争；
- 老龄化提高家庭老年人口占比；
- 极端事件在 100 次重复中产生可复现的非零显式失败率；
- 家庭就业、安居、教育和医疗使用不超过聚合容量；
- 家庭权重每年与聚合人口精确对齐。

方向测试只证明代码执行所声明的合成机制，不证明真实政策效应。

## 6. 验证闸门

| 门 | 判据 | 当前状态 | 失败动作 |
|---|---|---|---|
| U0 契约 | schema 与配置合法 | 通过 | 拒绝运行 |
| U1 政策证据 | 工具范围有来源；效应不冒充事实 | 通过（范围定义） | 拒绝正式情景 |
| U2 隔离 | 无私有路径、密钥和受限数据 | 通过 | 阻断发布 |
| U3 守恒 | 聚合账闭合，微观使用不超容量 | 通过 | 运行失败 |
| U4 行为方向 | 单元情景满足声明方向 | 通过（合成规则） | 修正规则 |
| U5 可复现 | 固定种子单次和重复结果一致 | 通过 | 阻断版本 |
| U6 校准 | 授权真实总体矩在预设容差内 | 未通过；接口已实现 | 只保留 Demo |
| U7 回溯/留出 | 历史或留出地区表现公开报告 | 未开始 | 降低使用等级 |
| U8 人工发布 | 专家确认假设、解释与边界 | 未签署 | 禁止决策材料发布 |

## 7. 使用等级

| 等级 | 条件 | 可用范围 |
|---|---|---|
| Demo | U0–U5 | 合成演示与软件测试 |
| Experimental | U0–U6 | 机制探索和研究讨论 |
| Analytical | U0–U7 | 内部方案比较，必须带区间 |
| Decision-support | U0–U8 | 面向管理者的辅助决策材料 |

当前插件等级为 **Demo**。任何 S0—S8、家庭分组或压力数值均不得用于真实地区决策。
