# 概念模型｜主体、机制与反馈

## 1. 模型边界

首版采用“合成家庭微观模拟 + 企业部门聚合 + 地方政府规则 + 空间分区”的混合结构。它优先表达市民化与承载能力，不追求完整城市一般均衡。

## 2. 主体与系统实体

| 对象 | 关键状态 | 主要决策/变化 |
|---|---|---|
| 家庭/个人 cohort | 户籍、常住地、年龄、技能、收入、家庭结构、住房、服务资格 | 迁移、落户、就业、住房与是否持续居住 |
| 企业部门 | 行业、岗位、技能需求、工资、产能、区位 | 招聘、扩张、收缩和区位选择 |
| 地方政府 | 预算、债务约束、土地、设施容量、政策工具 | 落户规则、服务扩容、住房、投资和空间配置 |
| 服务设施 | 教育、医疗、托育、养老等容量、质量、区位 | 容量利用、拥挤、扩容和服务范围 |
| 住房市场（首版聚合） | 供给、租金/价格、保障性住房、空置 | 成本变化与容量响应 |
| 空间单元 | 县城、重点镇、乡村、邻近中心城市 | 人口、岗位、设施与交通联系承载 |

## 3. 年度事件顺序

```mermaid
flowchart LR
    A["外生人口/经济/风险情景"] --> B["企业岗位与工资更新"]
    B --> C["家庭迁移和就业匹配"]
    C --> D["落户、住房和服务选择"]
    D --> E["设施拥挤与住房成本变化"]
    E --> F["政府收入、支出与项目执行"]
    F --> G["土地、设施和交通容量更新"]
    G --> H["年度指标与风险检查"]
    H --> A
```

事件顺序必须版本化，因为顺序本身会影响结果。

## 4. 核心机制

### 迁移与稳定居住

家庭比较预期就业收入、住房成本、公共服务、通勤成本、社会联系和迁移成本。输出是迁入、迁出、留居和落户倾向，不是对某个真实个人的预测。

### 就业匹配

岗位按行业和技能分组，家庭按技能匹配。产业政策首先改变岗位结构和工资分布，再影响迁移；禁止把投资额直接等同于人口吸纳。

### 公共服务容量

服务资格、设施容量、服务半径和拥挤共同决定实际可及性。落户放宽但不扩容时，模型应能显示覆盖率提高与服务拥挤之间的张力。

### 住房与安居

住房供给、租金/价格和保障性住房名额共同影响家庭是否长期居住。首版采用聚合响应函数，不模拟开发商竞价和金融体系。

### 财政—土地反馈

新增人口影响转移支付、税费与公共支出；项目占用预算和土地。若支出、债务或开发边界超限，场景必须触发约束，而不是继续产生无成本效益。

### 空间与都市圈联系

交通改善改变通勤和就业可达性，也可能形成中心城市就业、外围居住的分化。都市圈模块必须同时报告通勤收益、地方就业和公共服务压力。

## 5. 外生情景

- 宏观就业增长/衰退；
- 人口迁移增加/放缓；
- 财政转移与融资收紧；
- 房价/租金冲击；
- 老龄化和随迁子女规模变化；
- 极端降雨、公共卫生等压力事件。

## 6. 守恒与不变量

人口流入、流出、出生、死亡和期末人口必须守恒；岗位使用量不得超过岗位容量；服务使用不得隐式突破容量；预算、土地与项目时序必须闭合。无法闭合时运行失败，而不是只给警告。

## 7. LLM agent 边界

LLM 可用于生成受约束的利益相关者观点、辅助解释政策和提出待检验行为规则，不作为人口迁移概率、政策数字或因果效应的事实来源。任何 LLM 行为插件必须与规则型基线并行对照并报告重复运行稳定性。
