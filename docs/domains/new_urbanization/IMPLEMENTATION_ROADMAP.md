# 实施路线｜新型城镇化插件

## I0— I4（已完成）

- I0：政策基线、问题树、概念模型、指标数据、领域 schema 与注册骨架；
- I1：五类合成县城、六模块状态、年度调度和守恒测试；
- I2：七类注册工具、S0—S8、参数边界和组合风险；
- I3：一万户合成家庭、随机行为、五类压力、分组、重复和校准接口；
- I4：三类公平比较、群体差距、财政土地账、Pareto 前沿、一页纸和审计包。

## I5a 汇总数据适配协议（已完成）

- `AggregateDataAdapter` 抽象、注册装饰器、严格工厂和自动发现；
- 数据卡、八指标词典、单位、参考年份、授权和重复记录校验；
- 标准校准目标与逐指标来源追踪；
- 合成汇总 fixture、校准 CLI、Schema 和回归测试；
- 校准输出固定 `U6_status=not_passed`，避免软件通过冒充经验通过。

## I5b 授权汇总数据适配（待授权）

交付：指标词典 v2、来源与许可台账、真实来源私有读取器、缺失/修订/单位/行政区划报告，以及只含授权摘要的校准输入。

退出门：至少一个授权汇总数据案例可复现；公开仓库不含原始数据、凭据或本机路径；口径不清记录不进入校准。

## I6 真实校准、回溯与专家门

交付：校准前后差异、灵敏度、历史回溯、留出地区、外推边界、校准版模型卡和专家审阅。

退出门：U6 达到既定容差和留出标准后方可升级 Analytical；未过 U8 人工签署前不得标 Decision-support。

## I7 都市圈与更新韧性扩展

基础闭环稳定后再加入跨城通勤、产业分工、服务共享、城市更新和风险模块；不得并行堆叠导致无法归因。
