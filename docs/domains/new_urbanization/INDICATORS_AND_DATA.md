# 指标体系与数据计划

## 1. 指标分层

指标分为四层，避免把政策目标、模型状态和决策结果混成一张表。

| 层 | 作用 | 例子 |
|---|---|---|
| 政策承诺 | 政府文件中的目标与约束 | 城镇化率、服务覆盖、更新任务 |
| 状态变量 | 模型每期更新的系统状态 | 人口、岗位、设施容量、住房供给、预算 |
| 机制诊断 | 解释结果为何变化 | 技能错配、服务拥挤、住房负担、财政缺口 |
| 决策结果 | 比较方案优劣与风险 | 稳定市民化、群体差距、单位成本、约束触发 |

## 2. 核心结果指标

### 人口与市民化

- 常住人口城镇化率；
- 户籍人口城镇化率及两者差距；
- 新迁入、稳定居住、落户和返流人数/比率；
- 家庭完整迁移比例；
- 非户籍常住人口基本公共服务覆盖率。

### 就业与收入

- 就业率、稳定就业率和技能匹配率；
- 家庭可支配收入与城乡/户籍组差距；
- 通勤时间和就业可达性；
- 新增岗位中可由目标人群匹配的比例。

### 住房与公共服务

- 租购住房负担率；
- 保障性住房覆盖率；
- 教育、医疗、托育、养老容量利用率；
- 实际服务可及率、平均距离/时间和拥挤程度；
- 户籍与非户籍、不同收入组之间的服务差距。

### 财政与土地

- 市民化新增公共支出、转移支付和地方净财政成本；
- 每新增一名稳定市民化人口的财政成本；
- 项目资本支出、运营维护支出和债务压力；
- 新增建设用地、存量盘活、单位人口建设用地；
- 设施闲置率与扩容缺口。

### 空间、生态与韧性

- 县城—乡镇—乡村服务覆盖；
- 县城与邻近中心城市通勤可达性；
- 人口/岗位/服务空间匹配度；
- 开发边界或生态约束触发；
- 生命线、排涝和应急设施压力指标。

## 3. 决策合成原则

不设单一“城镇化综合分”。方案比较采用多目标前沿：市民化质量、效率、公平、财政可持续、空间集约和韧性并列。只有在用户显式给出权重时才生成加权排序，并同时显示未加权结果。

## 4. 数据分级

### D0 合成数据（MVP）

由公开代码生成家庭、岗位、设施、住房、财政和空间分区。所有记录标记 `synthetic=true`，用于验证守恒、行为方向、性能和输出解释。

### D1 官方汇总数据

用于校准人口、城镇化、就业、财政、公共服务、住房和土地等总体矩。数据适配器必须记录来源、年份、空间尺度、口径和许可，不把本机研究目录作为运行依赖。

### D2 授权空间数据

道路、设施、土地利用、风险和可达性数据按许可接入。公开仓库只保留下载/生成脚本和数据卡，不默认再分发受限文件。

### D3 评估与行为数据

迁移意愿、就业/住房选择和服务使用参数来自可核实调查、准实验或研究。未获得参数时使用显式先验区间做敏感性分析，不以模型主观设定冒充估计。

## 5. 最小数据合同

| 数据表 | 最小字段 |
|---|---|
| `population_state` | zone, cohort, hukou, residence, age_group, skill, household_type, weight |
| `labor_state` | zone, sector, skill, jobs, wage, stability |
| `housing_state` | zone, tenure, supply, cost, occupancy, affordable_quota |
| `service_state` | zone, service_type, capacity, quality, eligibility, travel_time |
| `fiscal_state` | government, revenue, transfer, operating_cost, capital_budget, debt_limit |
| `land_state` | zone, developable, used, stock_reusable, ecological_constraint |
| `policy_fact` | commitment_id, evidence_id, indicator, target, verification_status |

## 6. 口径风险

- 常住人口与户籍人口不可混用；
- 城区、城镇、县城、县域和行政区边界不可互换；
- 设施数量不等于服务能力，投资额不等于服务结果；
- 年度流量与期末存量不可直接相除；
- 规划目标、统计实际值和模型参数必须分表；
- 跨年区划变化必须显式对齐。

## 7. 汇总校准指标契约 v2

`aggregate_indicator_catalog_v2.csv` 冻结当前八个汇总校准指标与模型输出的映射。`required_caliber` 是接入前必须填写的口径要求，不是系统自动推断值；`real_data_eligibility=blocked` 的指标不得进入真实校准。

当前 `used_construction_land` 仍使用合成面积单位，因此真实数据资格为 blocked。其余七项也只有在授权、尺度、边界、分母和时间口径明确后才能标记为可用。现有默认容差仅服务合成 fixture，真实容差必须在查看结果前预注册。

## 8. 机器质量规则与人工口径门

机器规则只检查可以稳定编码的边界：人口和容量非负，城镇化率、就业率和住房入住率位于 0—100，数值有限，单位与目录一致，年份位于 2000—2100，来源和转换引用闭合。

机器不推断“常住/户籍”“工作年龄人口”“债务和收入覆盖”“床位/学位容量”或区划可比口径。真实数据中七个 conditional 指标必须进入人工口径审查；`used_construction_land` 在正式面积单位和转换协议冻结前保持 blocked。

质量报告通过只说明对象符合当前合同，不说明模型已校准、可外推或可用于决策。I5b、U6、U7 和 U8 继续按独立证据包裁定。
