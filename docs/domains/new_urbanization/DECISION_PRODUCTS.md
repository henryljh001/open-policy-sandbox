# 面向高层管理人员的决策产品

## 已实现出口

v0.5.0 将同一份合成比较结果生成四个相互校验的产物：

1. `comparison.json`：方案、指标、群体、资源与风险的机器结果；
2. `decision_brief.json`：固定结构的一页纸数据；
3. `decision_brief.md`：管理人员可直接阅读的简报；
4. `audit_bundle.json`：输入摘要、组件版本、随机设计、阈值和闸门状态。

命令：

```powershell
$env:PYTHONPATH = "src"
python scripts/compare_scenarios.py `
  --plan examples/new_urbanization/comparison_plan.json `
  --output-dir output/comparison_demo
```

## 比较纪律

- `policy` 模式固定县域、行为和压力，只允许政策包变化；
- `stress` 模式固定政策包，只允许外部压力变化；
- `joint` 模式允许政策与压力同时变化，但自动附加“不可单因归因”警告；
- 全部方案使用同一基础种子序列，降低随机比较噪声；
- 比较前对核心上下文计算摘要，不可比输入硬拒绝；
- 结果保留成功运行数、失败数和失败率。

## 一页纸固定结构

1. 一句话权衡判断；
2. 三条关键发现及证据字段；
3. 方案矩阵与 Pareto 前沿标记；
4. 各方案最大群体差距；
5. 财政、土地、服务、住房与模拟失败风险；
6. 最坏失效率情景；
7. 三项下一步动作；
8. Demo、合成假设、非推荐和 U6—U8 未通过声明。

## 不设隐藏综合分

系统不会自动把市民化、就业、住房、公共服务、财政、土地和风险压成一个分数。默认只计算无权重 Pareto 前沿：若一个方案至少在一个目标上更好，且在所有目标上都不更差，它才支配另一个方案。

Pareto 前沿仍不是政策推荐。价值权重只能由具名的人类决策责任人提供并记录，不能由模型或提示词代填。

## 群体与资源检查

群体结果按技能、来源、家庭结构和空间位置报告稳定市民化率，并显示最大—最小差距和最差群体。财政土地账并列显示债务收入比、财政支出收入比、建设用地、剩余可开发土地、服务可及、住房负担和失败率。

所有风险阈值均在 `decision_defaults.json` 和输出台账中可见。它们是合成演示假设，不是法定标准。

## 政策助手边界

政策助手可以解释有证据的政策条款、把管理问题转成结构化情景、解释结果差异、生成摘要草稿。

政策助手不可以自动签署事实、生成不存在的政策数字、替用户选择价值权重、隐藏不确定性、把情景结果称为预测或替代审批。
