# MVP 规格｜市民化 × 县城综合承载能力

> 状态：Accepted  
> 当前等级：Demo  
> 目标等级：Experimental（须通过 U6 真实总体矩校准）

## 1. 决策问题

对于一个给定类型的合成县域，在未来五年内，落户、就业、公共服务、住房和县城扩容如何组合，才能增加稳定市民化人口，同时不突破财政、土地和服务容量约束？

## 2. 空间与时间

- 空间单元：县城、重点镇、乡村、邻近中心城市；
- 时间步长：年度；
- 政策期：5 年，可配置 1—15 年；
- 聚合层：县域人口、就业、住房、服务、财政和土地；
- 家庭层：默认 1 万户合成家庭，可配置 100—10 万户；
- 重复运行：确定性基线 1 次，随机模型默认 100 次。

## 3. 最小机制模块

| 模块 | 当前功能 |
|---|---|
| 人口 | 聚合出生/死亡/净迁移；家庭迁入、迁出、落户和权重对齐 |
| 就业 | 聚合岗位容量；家庭技能概率匹配，使用量不超过岗位 |
| 住房 | 聚合供给；家庭安居概率、负担率和容量限制 |
| 公共服务 | 教育、医疗资格、使用和容量限制 |
| 财政 | 收入、转移、运营/资本支出、余额和债务 |
| 土地 | 新增建设用地、存量盘活和开发边界 |

聚合层是总量账权威来源；家庭层不得独立创造或删除总人口、岗位、住房和服务容量。

## 4. 政策与压力工具

七类政策工具：落户门槛、常住人口服务资格、技能就业、保障房、教育医疗扩容、市民化转移支付、用地与存量盘活。

五类压力工具：就业下行、财政收紧、迁入超预期、人口老龄化、极端事件扰动。所有工具均要求唯一注册名、配置驱动、显式合成效应和严格边界。

## 5. 最小输出

- 稳定市民化户数与率；
- 常住/户籍城镇化率差距；
- 就业、安居、服务可及和住房负担；
- 按技能、来源、家庭结构和空间位置的群体差距；
- 教育、医疗、岗位和住房容量使用；
- 五年财政、债务、土地和存量盘活；
- 重复实验均值、P05/P50/P95、标准差和失败率；
- 约束触发、警告、失败原因和复现摘要。

单位市民化成本和正式三方案一页纸在 I4 完成。

## 7. 明确不做

- 真实县域政策推荐；
- 个人级迁移、就业或落户预测；
- 房地产金融一般均衡；
- 建筑级更新、道路级拥堵或灾害水动力模拟；
- 把合成失败率写成真实灾害概率；
- 由 LLM 自由生成迁移概率、财政参数或政策效应。
