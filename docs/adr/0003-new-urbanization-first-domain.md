# ADR-0003：首个领域插件确定为新型城镇化

- 状态：Accepted
- 日期：2026-08-19

## 背景

政策沙盒需要一个同时具备明确政策链、跨主体反馈、空间差异和高层决策价值的首个领域。新型城镇化连接人口流动、就业、住房、公共服务、土地、财政、城市体系和治理，能够检验沙盒是否真正支持复杂治理问题。

## 决策

首个领域插件确定为“新型城镇化”，唯一注册名为 `new_urbanization`。领域插件负责声明政策问题、适用尺度、机制模块、配置约束和评价维度；具体求解仍交给可替换模拟引擎。

## 结果

优点：与现有政策研究积累和县域城镇化研究能力高度契合，可形成从政策解读到情景比较的完整示范。代价：领域边界宽，必须通过分层模块和 MVP 收缩防止一次性建成“大而全”模型。

## 边界

确认领域不等于确认所有子模块。首个 MVP 的具体切口由 ADR-0004 提出，仍需用户最终确认。
