# ADR-0002：模拟器、干预与指标采用注册表/工厂

- 状态：Accepted
- 日期：2026-08-19

## 背景

政策沙盒需要支持微观模拟、ABM、系统动力学以及交通、住房、公共服务等领域机制。如果主流程直接依赖具体实现，新增领域会造成条件分支堆叠，难以测试和治理。

## 决策

把模拟引擎、干预策略和指标计算器定义为独立插件类别。插件用唯一名称注册，由工厂从配置创建；约定包中的公开模块自动发现，未知名称和重复注册显式失败。

## 约束

- 构造参数只来自配置；
- 插件声明名称、版本、适用尺度和假设；
- 核心编排只依赖协议/抽象基类；
- 自动发现跳过以下划线开头的私有模块；
- 导入错误不得静默吞掉。

## 结果

新增领域不改核心流程，便于单独测试与发布。代价是插件接口需要版本治理，且自动导入必须控制供应链和副作用风险。
