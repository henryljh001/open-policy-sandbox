# ADR 0007：共同随机数与无隐藏综合分

- 状态：Accepted
- 日期：2026-08-19

## 背景

多方案模拟容易被两类问题污染：不同随机样本造成的比较噪声，以及未经说明的指标权重把多目标权衡压成单一排名。二者都会降低可审计性，并可能让管理者误把演示结果当成客观最优方案。

## 决策

1. 同一比较中的方案使用相同基础种子序列，形成共同随机数设计；
2. `policy`、`stress`、`joint` 三种模式分别冻结不同上下文，不可比输入硬拒绝；
3. 输出保留每个指标的分布、基线差值、方向和区间重叠；
4. 默认不生成综合分或全序排名；
5. 使用无权重 Pareto 前沿表达非支配集合；
6. 如未来加入权重，权重必须由具名人类责任人提供、版本化并进入审计包。

## 后果

共同随机数降低方案差值的随机噪声，但不能消除模型结构偏误。Pareto 前沿保留多目标权衡，却可能包含多个方案；系统必须把这种未决状态呈现给管理者，而不是暗中代替其价值判断。
