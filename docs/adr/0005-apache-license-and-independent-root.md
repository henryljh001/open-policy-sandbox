# ADR-0005：Apache-2.0 与独立项目根

- 状态：Accepted
- 日期：2026-08-19

## 决策

项目采用 Apache License 2.0。仓库根目录是公开应用的唯一工程根，源代码、包资源、schema、示例、测试和文档均在该根目录内闭合；研究原型和私有数据不作为依赖。

## 原因

Apache-2.0 允许宽松使用和再分发，同时明确专利授权与 NOTICE 义务，适合希望形成可扩展插件生态的开源软件。独立工程根可以防止本机路径、研究数据和临时产物渗入公开发行包。

## 后果

1. 发布包必须包含 `LICENSE` 和 `NOTICE`；
2. 修改和再分发须遵守许可证中的保留声明义务；
3. 贡献默认按 Apache-2.0 接收；
4. 项目不自动继承相邻研究目录的许可、数据授权或引用关系。
