# ADR-0011：U6/U7 两阶段预注册与一次性留出

- 状态：Accepted
- 日期：2026-08-20

## 背景

U6 校准规则必须在查看校准结果前冻结，但 U7 留出规则需要引用 U6 完成后产生的校准证据和最终模型摘要。若把两者封存在同一份预注册中，要么提前虚构尚不存在的最终模型哈希，要么在查看校准结果后修改原登记，都会破坏时间顺序和可审计性。

## 决策

1. 采用两份相互引用的预注册：`u6_calibration` 在查看校准结果前封存，`u7_holdout` 在 U6 完成后、查看留出结果前封存；
2. U6 冻结 I5b 证据引用、校准/留出分割、指标范围、实现版本、参数边界、总体矩容差、敏感性方案和最大校准次数；
3. U7 引用 U6 预注册与 U6 证据摘要，新增最终参数和模型冻结摘要、主验证指标、阈值、外推边界与独立验证角色；
4. 每份登记的 SHA-256 覆盖除自身摘要槽外的完整 JSON；非标准 JSON 数值不得获得摘要；
5. 跨阶段链校验强制 U7 与 U6 使用同一 I5b 证据、指标范围、数据分割和基础实现冻结，并精确引用 U6 登记摘要；
6. 留出验证最多执行一次。U7 登记封存时，执行次数必须为 1、消费状态为 false，且不得含尝试 ID、时间或结果摘要；
7. 预注册只描述结果查看前的规则，不嵌入校准或留出结果。结果由独立私有证据包记录；
8. 任何实质修改都产生新版本和新摘要。查看结果后修改规则会使原证据链失效，不能覆盖原登记；
9. 空白模板、Schema 和机器校验属于软件证据，不自动提升 I5b、U6、U7、U8 或 Demo 使用等级。

## 后果

U6 可以在不预知校准结果的前提下冻结目标和搜索边界；U7 可以在最终模型形成后、首次查看留出结果前冻结验证标准。代价是私有运行环境必须保留两份登记、U6 证据和一次性留出消费记录，并在执行前完成链校验。

公开仓库仅提供合成空白模板与校验代码，不保存真实数据摘要、结果摘要、责任人姓名或本机路径。
