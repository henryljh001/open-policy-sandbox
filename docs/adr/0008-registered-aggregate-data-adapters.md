# ADR 0008：注册式汇总数据适配器与严格失败

- 状态：Accepted
- 日期：2026-08-19

## 背景

真实治理数据来自不同发布者、年份、行政层级和单位。若模拟引擎直接读取来源文件，数据口径会渗入领域逻辑，难以测试、替换和审计；若未知字段自动回退，错误可能被静默带入校准。

## 决策

1. 建立独立 `AggregateDataAdapter` 抽象、注册表、装饰器和工厂；
2. 适配器只接收配置对象，输出标准校准目标和逐指标来源追踪；
3. 未知适配器、配置字段、指标、单位、年份和重复记录全部硬失败；
4. 模拟引擎不依赖适配器或文件系统，应用层负责编排；
5. 内置实现只接受合成 fixture，并声明 `accepts_real_data=false`；
6. 真实来源读取器需另行授权、版本化并在私有运行环境实现。

## 后果

新增数据源需要显式实现和契约测试，前期成本增加；但数据口径、许可和模型逻辑被隔离，适配器可独立替换，校准结果可以回指记录，且不会因默认回退而伪造成功。
