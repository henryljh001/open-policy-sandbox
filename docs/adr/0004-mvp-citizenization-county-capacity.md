# ADR-0004：MVP 聚焦市民化与县城承载能力

- 状态：Accepted
- 日期：2026-08-19

## 决策

第一条可运行纵切聚焦“农业转移人口市民化 × 县城综合承载能力”。空间上采用县城—重点镇—乡村—邻近中心城市四类区域，时间上采用年度步长和五年政策期。

## 原因

1. 能直接对应新型城镇化首要任务和潜力地区行动；
2. 可同时表达人口意愿、就业吸纳、住房负担、公共服务容量、财政与土地约束；
3. 县域公开汇总数据和合成微观人口均可支撑原型；
4. 比一开始模拟完整都市圈交通或建筑级城市更新更可控。

## 非目标

首版不模拟房地产市场一般均衡、不进行建筑级城市更新、不生成个人迁移预测，也不使用自由对话式 LLM agent 决定迁移行为。
