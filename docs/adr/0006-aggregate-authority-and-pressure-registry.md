# ADR-0006：聚合守恒权威层与压力插件

- 状态：Accepted
- 日期：2026-08-19
- 决策范围：I3 合成家庭、随机行为、压力和重复实验

## 背景

I2 已有县域聚合人口、就业、住房、服务、财政和土地账。I3 需要表达家庭异质性和随机分配，但若让聚合层与家庭层分别决定总人口和容量，模型会出现不可审计的双重记账。同时，外部压力若直接写进引擎分支，会破坏插件独立性和组合验证。

## 决策

1. 聚合模型是人口、岗位、住房、服务、财政和土地总量的唯一权威层；
2. 合成家庭样本每年只通过统一权重对齐聚合人口，不独立创造总量；
3. 家庭内部允许迁移状态、年龄构成、就业、落户、安居和服务状态变化；
4. 就业、安居、教育和医疗分配受聚合容量硬约束；
5. 压力作为第五类插件对象，使用唯一注册名、装饰器、工厂和自动发现；
6. 压力只编译配置中显式可见的聚合率与行为概率变化；
7. 重复实验只捕捉显式建模的随机失效，其他配置和程序错误继续向上抛出。

## 结果

- 优点：守恒责任单一，家庭分配可解释，压力可组合、可发现、可测试；
- 代价：家庭样本不能独立生成聚合人口反馈；更复杂的涌现机制需在 M2 另立接口；
- 边界：合成家庭与失败率均不代表真实个人或真实风险概率；U6 前保持 Demo。
