# 项目路径与边界

## 独立项目根

仓库根目录是本项目唯一的相对路径锚点。源代码不得假定仓库位于特定盘符、用户名目录或父项目下，也不得通过软链接、目录联接或相对上跳读取相邻研究项目。

## 公开目录

- `src/`：可安装 Python 包；运行时静态资源随包分发；
- `schemas/`：跨模块公开契约；
- `examples/`：全部标记为 `synthetic=true` 的可运行配置；
- `data/sample/`：允许公开的小体量合成数据；
- `docs/`：产品、架构、领域、治理和决策记录；
- `tests/`：单元、契约、路径独立性和守恒测试；
- `scripts/`：不依赖本机路径的维护命令。

## 非公开或临时目录

`data/private/`、`data/raw/`、`artifacts/`、`outputs/`、`_versions/` 和 `_复盘/` 不进入发布包或版本控制。真实数据适配器只能读取用户显式配置的输入位置，不能把位置写死在源代码中。

## 运行时路径规则

1. 包内合成资源通过 `importlib.resources` 读取；
2. 用户输入路径通过命令参数或配置传入；
3. 输出目录由调用者提供，默认不写入包目录；
4. 测试必须能够在任意当前工作目录下读取包内资源；
5. 隔离扫描发现本机绝对路径、密钥或受限二进制文件即失败。

## 版本隔离

正式版本快照放入 `_versions/`，只用于本地可恢复归档，不作为运行时依赖。公开 Git 仓库只跟踪当前正本；研究原型、私有台账和人工签署材料保持在独立项目中。
